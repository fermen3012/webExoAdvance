# Skill: Artesanía Visual & Diseño UI/UX

Esta skill rige los estándares visuales para garantizar consistencia y estética profesional.

## 1. Congelamiento y Preservación Visual
- Si un proyecto ya tiene un estilo visual definido (colores, bordes redondeados, tipografías, sombras), cualquier componente nuevo debe imitar exactamente dicho lenguaje visual.
- Prohibido mezclar estilos arbitrarios o añadir colores fuera de la paleta del sistema de diseño.

## 2. Responsividad y Accesibilidad
- Diseño adaptable (Mobile-First / Desktop-Ready).
- Contrastes legibles y zonas táctiles confortables (mínimo 44x44px para botones móviles).
